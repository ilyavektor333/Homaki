# GameSite

Локальный FastAPI-сайт с личным кабинетом, профилем игрока, экипировкой, составом клана и управлением должностями.

## Запуск

Дважды щёлкните `START.bat`.

Сайт откроется по адресу:

`http://127.0.0.1:8000/`

## Системный аккаунт

В начальной базе уже создан системный аккаунт с полными правами:

- Логин: `Admin`
- Должность: `Глава`
- Суперправа: да

Суперадминистратор видит раздел **«Управление должностями»** и может назначать игрокам:

- Глава
- Офицер
- Сержант
- Боец

Пароль системного аккаунта задан при первоначальной настройке проекта.

## Важно

Поле `is_superadmin` отделено от обычной должности. Это позволяет в дальнейшем независимо добавлять разрешения для каждой должности и сохранять один специальный аккаунт с полными правами.


## Активный состав
Системный аккаунт Admin управляет текущим активным составом через отдельную вкладку **«Активный состав»**. По умолчанию лимит — 33 человека. В обычном разделе «Состав Клана» активные игроки показываются сверху в порядке должностей, остальные скрыты внутри раскрываемого блока «Неактивный состав».

## Мероприятия и присутствие

В меню клана доступны отдельные разделы:
- Вечерний прайм
- Данж Гильдии
- Статистика присутствия

В каждом мероприятии есть календарь по месяцам и дням недели. Нажатие на день открывает активный состав клана. По умолчанию любой активный игрок может отметить только себя. Системный аккаунт Admin может в панели управления переключить режим каждого мероприятия на «только системный аккаунт».

Статистика поддерживает периоды: текущая неделя, текущий месяц и всё время, а также фильтр по конкретному мероприятию.
